# Contratos

Aquí viven los contratos **estables** entre piezas o con el exterior. Un archivo por contrato; se crea cuando una spec lo fija.

| Contrato | Qué define | Spec | Estado |
|---|---|---|---|
| Config de allowlist (`umbra.config.json` o similar) | formato de objetivos autorizados | 001 | por definir |
| Interfaz de módulo (`run(ctx)`) | cómo se escribe un módulo | 003 | por definir |
| JSON del reporte | salida de `report` y respuesta de la API | 005 / 006 | por definir |
| API de escaneo | request/response de los endpoints | 006 | por definir |

`Finding` (modelo base) está descrito en `dominios/confianza.md`.
